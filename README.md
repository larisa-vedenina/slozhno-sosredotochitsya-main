# No Focus - Исследование концентрации внимания

Адаптивный лендинг, посвященный проблемам концентрации внимания в современном мире. Проект демонстрирует современные подходы к верстке и UX/UI дизайну.

## Демо

[Открыть проект](https://larisa-vedenina.github.io/slozhno-sosredotochitsya-main/)

## Особенности

- **Адаптивный дизайн** - корректное отображение на всех устройствах
- **Кроссбраузерная верстка** - поддержка современных браузеров
- **Темная/светлая тема** - переключение между темами с сохранением состояния
- **Семантическая разметка** - правильная структура HTML для SEO и доступности
- **Оптимизация производительности** - lazy loading изображений, минимизация CSS
- **Доступность (a11y)** - поддержка скринридеров, правильная семантика

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - Flexbox, Grid, CSS Variables, Media Queries
- **Vanilla JavaScript** - переключение тем, интерактивность
- **Git** - контроль версий

## Ключевые решения в верстке

### Семантика
- Использование правильных HTML-тегов (`article`, `section`, `nav`)
- ARIA-атрибуты для улучшения доступности
- Логическая структура заголовков

### Адаптивность
- Mobile-first подход
- Гибкие сетки на CSS Grid и Flexbox
- Оптимизированные медиа-запросы

### Производительность
- Lazy loading для изображений
- Оптимизированные CSS-стили
- Минимизация перерисовок

## Установка и запуск

1. Клонируйте репозиторий:

git clone https://github.com/larisa-vedenina/slozhno-sosredotochitsya-main.git

2. Перейдите в директорию проекта:

cd slozhno-sosredotochitsya-main

3. Откройте index.html в браузере или используйте Live Server:

npx live-server
